# P2 補資料 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `ingest_espn` 能回補 2015-16～2022-23，並為所有季別寫入出賽狀態、裁判、中立場地、出手距離桶與標示時間點的盤口，且不會刪到 P1 的即時盤口快照。

**Architecture:** 全部改動集中在 `jobs/ingest_espn.py` 與 `jobs/schema.py`：`parse_summary` 擴充成回傳 NamedTuple，`ingest_dates` 多寫三張新表，盤口回填改成「只補缺的、不刪」。先以特徵化測試鎖住 `parse_summary` 既有輸出。

**Tech Stack:** Python 3.11、psycopg2、pytest。不新增依賴。

**Spec:** `docs/superpowers/specs/2026-10-24-p2-backfill-design.md`（必讀）。

## Global Constraints

- 遵守 `CLAUDE.md`；動 schema、ingest 前依 CLAUDE.md 先進 plan mode 確認本計畫（需使用者在實作 session 核准）。
- 分支：從 `main`（目前 `0efc9b1`，已含 P0、P1；本機 `p1-daily-data` 另有 docs-only commit，先 `git merge --ff-only p1-daily-data` 帶進來）開 `p2-backfill`。
- 檔案讀寫 `encoding="utf-8"`；測試不打網路、不連 DB（ESPN 用 `tests/fixtures/espn/` 存檔樣本；DB 用 monkeypatch 假連線）。
- 新表、新欄位只用 `CREATE TABLE IF NOT EXISTS`／`ADD COLUMN IF NOT EXISTS`；`SCHEMA_VERSION` `"3"` → `"4"`。不改既有表的主鍵或唯一鍵；`v_app_board` 不動。
- `parse_summary` 的 `team_rows`、`player_rows` 輸出不得有任何變化；`player_game_stats` 不新增 DNP 列。
- 隊名只走 `normalize_espn_abbr`；未知縮寫維持現行「該場警告後略過」。
- 數值：距離原點 (25, 0)；`dist_bucket` 邊界 4／8／14／24 呎（左閉右開）；`corner` = 3 分且 y ≤ 9；座標 |x| > 1000 或缺失為 `'unknown'`。
- 季別視窗：2015-16～2018-19、2021-22、2022-23 為 `(date(Y,10,1), date(Y+1,6,30))`；2019-20 為 `(date(2019,10,1), date(2020,10,15))`；2020-21 為 `(date(2020,12,1), date(2021,7,31))`。
- Streamlit golden 不得變動；每個 task 結束跑 `python -m pytest tests -q` 並貼輸出。
- **不 push、不寫正式 DB、不觸發 workflow**，直到第 7 章由主線逐項取得使用者同意。

## Review Focus

1. P1 之後只有即時快照（`captured_at` ≠ 開賽時間）的比賽：`backfill_odds_missing` 必須略過，`--force-rebuild` 也不得刪到它們。→ Task 4。
2. 一場比賽有 play 沒有 `team` 或 `team.id` 對不回 box score 的隊伍：不計入任何隊，不 raise。→ Task 2。
3. 舊季 summary 缺 `gameInfo.officials` 或為空：寫 0 列，不 raise。→ Task 2。
4. 被驅逐（`ejected`）但有上場數據的球員：`player_rows` 仍有該球員、`status_rows` 標 `ejected=True`。→ Task 2。
5. 讓分有 close、總分只有 current：兩個 point 分別標示，不混成一個。→ Task 4。
