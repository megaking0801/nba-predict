## 1. 環境（約 5 分鐘）
```bash
gh auth login                 # 資料 repo 是 private，要先登入 GitHub
git clone https://github.com/megaking0801/nba-predict.git && cd nba-predict
scripts/setup.sh              # 自動 clone／更新資料 repo、Python 3.11 venv、依賴、DATABASE_URL；--with-tests 另外跑測試（約 3 分鐘）
```
- 唯一的密鑰是 `DATABASE_URL`，腳本會問一次：先貼 Supabase 的 URI（保留 `[YOUR-PASSWORD]`），再輸入隱藏的密碼。密碼會自動 URL 編碼並寫進 `.streamlit/secrets.toml`（已被 `.gitignore` 擋住、權限 600）。
- Supabase 位置：Project2（ref 以 `rzei` 開頭）→ Connect → URI → Session pooler（埠 5432）。Project1（`vciz` 開頭）不要動。
- 公開 repo 不寫完整的 project ref。
- 已有可用的 `secrets.toml` 時，重跑 `setup.sh` 只會確認連線，不會再問。

## 4. 台彩資料的決定（2026-10-28）
- 使用者決定：**先用國際盤做完回測，再用估計賠率推算台彩**（`taiwan_est_1.75`）。台彩抽水較高，國際盤不賺的玩法台彩一定更不賺，所以不需要實際台彩賠率就能下這個判斷。
- **不繞過 Cloudflare**。官網 `services/content/get` 對無瀏覽器的請求回 403（Cloudflare 驗證頁）。使用者曾要求偽裝，已拒絕；使用者隨後改為「先不用」。
- 舊文章的 `blob.sportslottery.com.tw/apidata/Live/On.json` 是**場中即時盤**，不含賽前盤，普通 GET 回 `200` 與空陣列 `[]`。
- 使用者提供的 HAR 檔（官網籃球頁）顯示：NBA 聯賽節點 `34801.1`（`focontentid` 22064），賽前盤群組 `eventGroup` `60067.1`；先 `subscribe`，賠率再由 SockJS 推送通道送來，HAR 沒錄到內容。HAR 含 cookie，不進 repo（放在 repo 外的 `~/Documents/nba/download`）。
- 若之後要台彩賽前盤：用使用者自己的 Chrome（Claude in Chrome 讀頁面），或 Jbot。台彩只給現在的盤，要回測得自己每天存快照。

## 7. 2026-10-28 晚的決定與進度（主線）
- **ESPN 使用條款**：Disney 通用條款寫不得以 robot／script 自動存取、不得整理資料集，授權限個人非商業（ESPN 專屬條款未讀到；內容經小模型摘要，使用者要自行讀原文）。使用者決定**照現狀繼續**，條件：個人研究與朋友使用、不商業化、不收費、不對外轉貼原始資料。風險主要是接口被封（網站停止更新）。若要商業化，必須先換成條款明確允許的資料來源。
- **不賣會員／明牌**：自己的回測顯示讓分、大小分、不讓分（部分資料）、串關與模型挑選全部負報酬，收費推薦會誤導付費者並有不實廣告／詐欺風險。可做的是免費資訊站＋教育內容 SEO。
- **學習曲線**：fs1 ridge 約 3 個球季攤平，資料量不是缺口（`2026-10-28-learning-curve.md`）。
- **不讓分部分回測**（1,399 場，2015-17）：押熱門 −1.8%、冷門 −6.9%、主 −2.6%、客 −6.2%，模型挑選 −3%～−11%，全部不通過。完整 fetch 沒跑完（已停；資料在 `data/moneylines.jsonl.gz` 共 1,421 場，**尚未推到資料 repo**）。
