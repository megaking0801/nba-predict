# 學習曲線：fs1 ridge 的訓練資料量 vs 誤差（2026-10-28，只讀）

結論先講：**曲線在約 3 個球季就攤平。再加資料每翻一倍只降約 0.016 MAE，而離盤口還差 0.36。資料量不是缺口。**

## 設定
- 模型：fs1 ridge（`RIDGE_ALPHA=10`，與正式版相同）。對照：只用 `elo_diff` 的 ridge。
- 評分場次固定：2022-23～2024-25，regular＋playoffs＋playin，且有收盤盤口，共 **3,913 場**。每個訓練量都在同一批場次上評分。
- 訓練量：walk-forward（14 天一折，與 `jobs.evaluate` 同）的每一折只用「開賽日前最近 N 場 eligible 比賽」訓練。N 從 800 起以對數刻度到「全部」（擴張窗，等同 `jobs.evaluate`）。測試確認 N=全部 與 `walk_forward` 逐列一致。
- 區間：以 14 天為一塊的 block bootstrap，95%，2000 次。配對 ΔMAE ＝ 模型每場絕對誤差 − 對照每場絕對誤差（負＝模型較好）。
- 盤口 MAE ＝ 10.395（以 `-home_spread` 為盤口隱含的主隊分差）。

## 回答
1. **攤平了嗎？** 是。2.3 季以後與「全部」的差距的 95% 區間都包含 0；最後四點的最小平方斜率是 **−0.016 MAE／每翻一倍**（Elo：−0.003）。
2. **再加資料能降多少？** DB 只有約 10 季，沒有更多可測；用斜率外推，從 8 季翻到 16 季約降 **0.016**（外推，不是實測），約為與盤口差距 0.36 的 4%。要靠加資料追平盤口，需要翻倍二十次以上，不成立。
3. **ridge 比 Elo 好多少？** 全資料時 10.754 vs 10.869（差 0.115），但 ridge 要約 3 季才拿到這個優勢；Elo 只要不到 1 季。
4. 兩者離盤口都有穩定缺口（ridge +0.36、Elo +0.47，區間不含 0）。這與 `p5-market-baseline.json` 的 +0.358 一致。

## 限制（讀數字時要記得）
- 特徵（Elo、近期戰績等）仍用完整歷史建出來；本實驗只改「回歸」看到多少訓練列，不是「完全沒有歷史」的情境。
- `RIDGE_ALPHA` 固定 10，沒有隨訓練量重調；小樣本時調大 alpha 可能略改善左端，不會改變「右端已平」的結論。
- 用「最近 N 場」而不是「最早 N 場」：小 N 的訓練集全是近期比賽，可能比「任意年代的 N 場」更好，曲線左端因此可能偏低、整體看起來偏平；右端的「全部」則混入較舊賽季。這會影響曲線形狀，但不影響主結論：整條曲線的總落差約 0.15，盤口缺口是 0.36。
- 約幾季＝訓練場數／1,320（只是標示，各季場數略有不同）。
- 未做：HGB、不同特徵集、以 totals 為目標的曲線。
